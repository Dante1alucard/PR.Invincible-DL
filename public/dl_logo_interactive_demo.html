Глоу-эффект:
⚡ Как подключить на сайт с точной коллизией и обтекающим Glow:
1. Без фона: файл dl_logo_final_transparent.png (чистая альфа).
2. Глоу строго по буквам: используется CSS filter: drop-shadow(...), а не box-shadow!
3. Хитбокс строго по шипам: подключается через clip-path: polygon(...) или файл dl_logo_interactive.svg: 

.logo-btn {
  
  filter: drop-shadow(0 0 10px rgba(255, 255, 255, 0.8));
  transition: filter 0.3s ease, transform 0.2s ease;
}

.logo-btn:hover {
  
  filter: drop-shadow(0 0 20px #ffffff) drop-shadow(0 0 35px #a0c4ff);
  transform: scale(1.05);
}
